# 🌐 Calculadora de Subneteo

<div align="center">
  <img src="https://media.giphy.com/media/v1.Y2lkPTc5MGI3NjExNjZlMzRkMzRiMzRiNTRlMzI0YzJkZDRiMzI0ZDM0ZDM0YjU0ZTMyNCZlcD12MV9pbnRlcm5hbF9naWZzX2dpZklkJmN0PWc/3oKIPEqDGUULpEU0aQ/giphy.gif" width="500" alt="Networking GIF">
</div>

Una herramienta web interactiva y profesional para calcular máscaras de subred óptimas basadas en el número de hosts requeridos. Diseñada para administradores de red, estudiantes de redes y profesionales de TI.

## ✨ Características

<div align="center">
  <img src="https://media.giphy.com/media/v1.Y2lkPTc5MGI3NjExZjM0YjU0ZTMyNGMyZGQ0YjMyNGQzNGQzNGI1NGUzMjRjMmRkNGImZXA9djFfaW50ZXJuYWxfZ2lmc19naWZJZCZjdD1n/l3vRfNA1p0rvhMSvS/giphy.gif" width="400" alt="Features GIF">
</div>

- 🧮 **Cálculo automático** de la máscara de subred óptima
- 🔢 Visualización de resultados en formato **decimal, binario y notación CIDR**
- 📊 Información adicional sobre **dirección de red, broadcast y rango de hosts**
- 📝 **Historial de cálculos** guardado en localStorage
- 🌓 Modo **oscuro/claro** para mayor comodidad visual
- 📱 Interfaz **responsiva** para dispositivos móviles y de escritorio
- 📚 Sección **informativa** sobre conceptos de subneteo

## 📋 Cómo usar

<div align="center">
  <img src="https://media.giphy.com/media/v1.Y2lkPTc5MGI3NjExZjM0YjU0ZTMyNGMyZGQ0YjMyNGQzNGQzNGI1NGUzMjRjMmRkNGImZXA9djFfaW50ZXJuYWxfZ2lmc19naWZJZCZjdD1n/xT9IgzoKnwFNmISR8I/giphy.gif" width="400" alt="How to Use GIF">
</div>

1. 🔢 Ingresa el número de hosts requeridos en tu subred
2. 🖱️ Haz clic en "Calcular"
3. 📊 Revisa los resultados detallados y la explicación del cálculo
4. 💾 Consulta el historial de cálculos anteriores
5. 🌓 Cambia entre modo oscuro y claro según tu preferencia

## 🚀 Instalación

```bash
# Clona este repositorio
git clone https://github.com/joseorteha/calculadora_de_subneteo.git

# Navega al directorio del proyecto
cd calculadora_de_subneteo

# Abre index.html en tu navegador
# No se requieren dependencias adicionales
```
