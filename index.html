Información sobre Subneteo

¿Qué es el Subneteo?

El subneteo es el proceso de dividir una red IP en subredes más pequeñas para mejorar la eficiencia, seguridad y administración de la red.

Clases de Direcciones IP

  • Clase A: 1.0.0.0 a 126.255.255.255 (Máscara: 255.0.0.0)
  • Clase B: 128.0.0.0 a 191.255.255.255 (Máscara: 255.255.0.0)
  • Clase C: 192.0.0.0 a 223.255.255.255 (Máscara: 255.255.255.0)

Fórmulas Importantes

  • Hosts por subred: 2h - 2 (donde h = bits de host)
  • Número de subredes: 2s (donde s = bits de subred)
  • Bits totales: 32 bits (IPv4)

Consejos para el Subneteo

  • Siempre reserve suficientes direcciones para futuros dispositivos
  • Considere la segmentación lógica de su red
  • Documente su esquema de subneteo
